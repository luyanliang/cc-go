# Spec Delta

## Purpose

转录列表的滚动结构升级为居中锚定：历史向上增长、流式内容向下增长都不移动用户正在观看的位置，贴底时自动跟随，并提供回到底部入口。

## ADDED Requirements

### Requirement: 居中锚定不跳动

转录列表 SHALL 采用居中锚定结构：列表内容在视口中划分为锚点上方与下方两段，打开会话加载历史、流式追加新条目、既有条目更新时，用户当前正在查看的内容在视口中的位置 MUST NOT 因另一侧的内容增长而移动。

#### Scenario: 加载更早历史不动当前视点
- **WHEN** 用户停留在列表中部查看某条消息，更早的历史被加载插入列表顶部
- **THEN** 当前正在查看的消息在屏幕上的位置保持不变

#### Scenario: 流式追加不动当前视点
- **WHEN** 用户上翻查看历史，同时助手回复仍在流式增长
- **THEN** 列表底部新增内容不改变用户当前查看位置

### Requirement: 贴底跟随

当列表滚动位置处于贴底状态时，新内容到达 SHALL 在同一次布局内使列表继续贴底，不出现可感知的跳动或延迟回弹；用户一旦向上滚动 SHALL 立即停止跟随。

#### Scenario: 贴底时流式输出跟随
- **WHEN** 用户处于贴底状态且助手回复流式输出
- **THEN** 列表始终显示最新内容，无跳动

#### Scenario: 上翻即停止跟随
- **WHEN** 贴底跟随中用户向上滑动
- **THEN** 跟随立即停止，后续新内容不把视口拉回底部

### Requirement: 回到底部键

列表未处于贴底状态时 SHALL 显示"回到底部"浮动键；点击后平滑滚动到最新内容并恢复贴底跟随。贴底状态下该键 MUST 隐藏。

#### Scenario: 上翻后出现回到底部键
- **WHEN** 用户向上滚动离开贴底状态
- **THEN** 出现回到底部浮动键

#### Scenario: 点击回到底部
- **WHEN** 用户点击回到底部键
- **THEN** 列表滚动到最新内容，键消失，贴底跟随恢复
