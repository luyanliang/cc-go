# Spec Delta

## Purpose

消息级交互补齐：长按菜单、引用追问、排队消息撤回/编辑重发、回合末操作行、密钥屏显遮罩与图片动作，使消息成为可操作的对象而不只是展示单元。

## ADDED Requirements

### Requirement: 长按消息菜单

长按用户消息或助手消息 SHALL 弹出消息菜单，至少提供：复制全文、选择文字（进入系统文本选择）、引用（进入引用追问）。菜单操作 MUST 只作用于被长按的那条消息。

#### Scenario: 长按助手消息复制
- **WHEN** 用户长按一条助手消息并选择"复制"
- **THEN** 该条消息的 Markdown 原文进入剪贴板

#### Scenario: 长按用户消息选择文字
- **WHEN** 用户长按一条用户消息并选择"选择文字"
- **THEN** 进入系统文本选择模式，可部分选中复制

### Requirement: 引用追问

用户 SHALL 能引用某条消息发起追问：被引用消息摘录以引用胶囊形式显示在输入框上方，可取消；随消息发出时引文 MUST 以 Markdown blockquote 前缀并入发送文本，引用胶囊随之清除。

#### Scenario: 引用后发送
- **WHEN** 用户引用一条助手消息并输入"这里为什么报错"后发送
- **THEN** 发送文本以该消息的 blockquote 引文开头，输入框上方引用胶囊消失，用户气泡内可见引用块

#### Scenario: 引用可取消
- **WHEN** 用户点击引用胶囊上的取消
- **THEN** 引用被清除，发送的文本不含引文

### Requirement: 排队消息撤回与编辑重发

处于排队状态（尚未随当前轮送出）的消息 SHALL 可撤回（从队列移除且不出现在转录用户条目中）与编辑后重发（替换队列原文）。已送出的消息 MUST NOT 可撤回。

#### Scenario: 撤回排队消息
- **WHEN** 会话运行中用户连发两条消息进入队列，随后撤回第一条
- **THEN** 第一条从排队气泡中消失且不进入转录，第二条仍在队列中

#### Scenario: 编辑后重发
- **WHEN** 用户对一条排队消息选择编辑、修改文本后确认
- **THEN** 队列中该条文本被替换为编辑后的内容

### Requirement: 回合末操作行

一轮的最后一条助手消息下方 SHALL 显示安静的操作行（图标形式，不抢视觉），至少提供：复制、分享（系统分享面板）、引用。操作行 MUST 只在回合完成后出现，流式期间不显示。

#### Scenario: 回合完成后出现操作行
- **WHEN** 一轮正常完成
- **THEN** 最后一条助手消息下方出现复制/分享/引用操作行

#### Scenario: 流式中不显示
- **WHEN** 助手消息仍在流式输出
- **THEN** 该消息下方不出现操作行

### Requirement: 密钥屏显遮罩

用户已发送消息中的疑似凭据（API key、令牌、私钥片段、URL 中的密码）SHALL 在屏幕上以遮罩形态显示（等宽 chip，可逐段点开查看）；遮罩 MUST 只影响显示——复制、引用、编辑与实际发送的文本均为原文。误报 SHALL 允许（宁多勿漏），但 MUST NOT 改变消息数据本身。

#### Scenario: 发送密钥后屏显遮罩
- **WHEN** 用户发送包含 API key 的消息
- **THEN** 用户气泡中该 key 显示为遮罩 chip，点开可查看原文

#### Scenario: 复制拿到原文
- **WHEN** 用户复制（或引用）一条含遮罩的用户消息
- **THEN** 剪贴板内容为原文而非遮罩占位

### Requirement: 图片消息动作

已发送消息中的图片附件与工具结果图片 SHALL 支持长按操作：保存到系统相册、通过系统分享面板分享。全屏查看器的现有缩放/关闭能力 MUST 保留。

#### Scenario: 保存图片到相册
- **WHEN** 用户长按一条用户消息中的图片附件并选择保存
- **THEN** 图片写入系统相册并给出成功反馈
