# Spec Delta

## MODIFIED Requirements

### Requirement: 会话列表
App SHALL 按项目分组展示 daemon 管理的全部会话，每项含标题、工作目录、状态（空闲/运行中/待权限）、更新时间与来源（cc-go 创建/导入接管）；列表 MUST 在收到会话变更事件时自动刷新；处于待权限状态的会话 SHALL 以更醒目的方式呈现。每组 SHALL 提供该项目的会话历史入口。

#### Scenario: 打开即见列表
- **WHEN** 已连接用户打开会话列表
- **THEN** 会话按项目分组显示，每项含标题、目录、状态、更新时间与来源

#### Scenario: 事件驱动刷新
- **WHEN** 连接期间收到会话变更事件
- **THEN** 列表自动更新，无需手动刷新

#### Scenario: 项目历史入口
- **WHEN** 用户点按某项目分组的历史入口
- **THEN** 进入该项目的 Claude Code 会话历史列表（含终端创建的会话）

### Requirement: 新建会话
用户 SHALL 能从会话列表创建新会话：注册表仅有默认项目时直接使用该目录；存在多个已注册项目时 SHALL 先选择项目目录再创建，并直接进入其聊天页。

#### Scenario: 新建并进入
- **WHEN** 仅存在 daemon 启动目录一个项目且用户点击新建
- **THEN** 在该目录创建新会话，列表更新，并导航到该会话的聊天页

#### Scenario: 多项目选择目录
- **WHEN** 存在多个已注册项目且用户点击新建
- **THEN** 先呈现项目目录选择，选择后在新目录创建会话并进入聊天页
