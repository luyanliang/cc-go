# Spec Delta

## Purpose

daemon 侧的项目目录管理：以白名单方式声明允许操作的项目目录，手机端按项目组织与创建会话。

## ADDED Requirements

### Requirement: 项目目录白名单
daemon SHALL 维护一个项目目录注册表；会话的创建与历史会话的导入 MUST 仅允许发生在已注册目录内。注册途径 SHALL 包含启动参数注册与运行期通过已认证连接注册；注册表 MUST 持久化并在重启后保留。daemon 启动时若注册表为空，SHALL 将启动目录注册为默认项目。

#### Scenario: 启动参数注册
- **WHEN** daemon 以 `--project <目录>` 参数启动且该目录存在
- **THEN** 该目录进入注册表并出现在项目枚举结果中

#### Scenario: 未注册目录被拒绝
- **WHEN** 已认证客户端请求在未注册目录中创建或导入会话
- **THEN** 请求失败并返回可理解的错误说明，不产生任何会话

#### Scenario: 首次启动的默认项目
- **WHEN** daemon 启动且注册表为空
- **THEN** daemon 的启动目录被注册为默认项目，现有"默认目录新建会话"行为保持可用

### Requirement: 项目枚举
daemon SHALL 通过 `projects.list` 向已认证客户端返回全部已注册项目目录，每项包含规范化的目录路径、显示名（目录基名）与该目录下的 cc-go 会话计数。已注册但在文件系统上不存在的目录 MUST 被标记为不可用而非从结果中隐藏。

#### Scenario: 枚举已注册项目
- **WHEN** 已认证客户端调用项目枚举
- **THEN** 返回每个已注册目录的路径、显示名与会话计数

#### Scenario: 目录失效标记
- **WHEN** 某已注册目录在文件系统上已被删除
- **THEN** 枚举结果仍包含该目录并标记为不可用

### Requirement: 按项目分组的会话列表
手机端会话列表 SHALL 按项目目录分组展示会话；每组 SHALL 呈现项目显示名，组内为属于该目录的 cc-go 会话（含导入的历史会话）。会话归属 MUST 以会话创建/导入时确定的工作目录为准。

#### Scenario: 多项目分组展示
- **WHEN** 已连接用户打开会话列表且存在多个项目下的会话
- **THEN** 会话按项目分组呈现，每组标题为项目显示名

#### Scenario: 空项目呈现
- **WHEN** 某已注册项目下没有任何会话
- **THEN** 该项目分组仍可见，并提示可新建会话

### Requirement: 选择目录新建会话
用户在手机端新建会话时 SHALL 从已注册且可用的项目目录中选择一个；会话 MUST 在所选目录中创建。不可用的项目目录 MUST 无法被选中。

#### Scenario: 选择项目创建
- **WHEN** 用户在新建会话时选择某已注册目录并提交
- **THEN** 会话在该目录中创建，列表对应分组更新，并导航到聊天页

#### Scenario: 仅有默认项目时
- **WHEN** 注册表中只有 daemon 启动目录一个项目
- **THEN** 新建会话无需选择，直接使用该目录
