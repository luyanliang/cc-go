# Spec Delta

## Purpose

转录与会话的数据细节：工具调用的原始结果（完整文本与图片）不再被压成单行摘要，会话的 token 用量与成本对手机端可见。

## ADDED Requirements

### Requirement: 工具原始文本输出
ToolItem SHALL 携带工具结果的完整文本（保留换行，超过上限时截断并标记），替代仅单行摘要；daemon 与历史回放 MUST 填充同一字段，旧数据无该字段时回退既有摘要展示。

#### Scenario: 完整输出可见
- **WHEN** 用户展开一个有长输出的 Bash 工具行
- **THEN** 展开内容显示多行完整输出，而非压成单行的摘要

#### Scenario: 超限截断标记
- **WHEN** 工具结果文本超过上限
- **THEN** 展示截断后的文本并明确标注已截断

#### Scenario: 旧数据回退
- **WHEN** 转录条目没有原始输出字段（历史存量数据）
- **THEN** 工具行照常以摘要展示，不报错

### Requirement: 工具结果图片
工具结果携带的图片 SHALL 随 ToolItem 下发（限定数量与体积），并在工具行展开时展示。

#### Scenario: 结果图片展示
- **WHEN** 用户展开一个返回图片的工具调用
- **THEN** 展开内容显示结果图片，点开可放大查看

### Requirement: 用量与成本展示
daemon SHALL 从回合结束的 result 消息提取 token 用量与累计成本，随会话摘要下发；App SHALL 在聊天页展示当前会话的累计成本与最近一次的上下文用量。

#### Scenario: 成本随摘要更新
- **WHEN** 一个回合正常结束
- **THEN** 会话摘要携带更新的用量数据，聊天页展示的成本随之刷新

#### Scenario: 无数据时不展示
- **WHEN** 会话尚无任何用量数据（如旧 daemon 或回合未结束）
- **THEN** 用量区域不显示，不出现占位零值
