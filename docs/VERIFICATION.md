# 验证与真机验收

## 自动检查

仓库根目录执行 `bash scripts/check.sh --setup`（首次或依赖变化）或 `bash scripts/check.sh`（依赖已安装）。该检查覆盖 daemon 类型检查、Vitest、构建、Flutter 静态分析、Flutter 测试和 OpenSpec 严格校验。daemon 的 `server.test.ts` 使用临时存储和随机本机端口，不需要 Claude 登录；`smoke-client.mjs` 才会实际驱动 Claude CLI。

## 第 8–9 节真机步骤

准备：在终端运行 daemon；确认手机能连到 daemon，记录手机型号、Android 版本、App commit、daemon commit、网络类型、证书指纹和测试时间。确认 Android 通知权限已开启。

公网冒烟客户端需能运行已登录的 Claude CLI，先创建 `/tmp/ccgo-test`，再从 `daemon/` 执行：`node test/smoke-client.mjs 654321 --host <服务器地址> --port 8747 --fingerprint <daemon 启动时打印的指纹>`。

| OpenSpec 任务 | 操作 | 通过条件 |
| --- | --- | --- |
| 8.1 后台保活 | 进入会话后锁屏 30 分钟；期间从电脑侧触发会话事件；解锁核对到达时间和常驻通知状态 | 锁屏期间事件仍实时到达，通知状态与连接一致 |
| 8.2 权限通知 | App 退后台；电脑侧触发需确认的工具；点击权限通知 | 出现高优先级通知，点按进入对应会话并可处理权限 |
| 8.3 轮次结束 | 后台运行一轮到结束；前台再运行一轮 | 后台只收到一次结束通知，前台不出现结束通知 |
| 8.4 断线恢复 | 开关飞行模式；观察状态提示和恢复；检查电池优化引导的跳过与设置路径 | 断线状态清晰，网络恢复后自动重连，引导可跳过 |
| 9.1 公网全链路 | 公网环境依次配对、新建、发送、后台授权、等待结束、断网重连，并运行带 `--fingerprint` 的冒烟客户端 | 全链路恢复无需人工干预，冒烟测试通过 |

每项记录实际结果及失败现象；未执行或未通过的任务保持 `- [ ]`。真机通过后再更新 OpenSpec 任务，并把证据摘要附在对应提交或评审说明中。构建 APK、单元测试或静态检查通过，均不能替代这些步骤。

## ssh-tunnel-mdns-qr-pairing 真机步骤

准备：
- daemon 侧：`node bin/cc-go.mjs --code 654321`（默认 LAN 模式，横幅含二维码与 mDNS 广播）；SSH 场景另起 `node bin/cc-go.mjs --localhost --code 654321`（不广播）。
- 手机与电脑同一局域网；SSH 场景需电脑侧 sshd 开启且手机可免密/密码登录。
- 安装 debug 或 release APK 后记录 App commit 与 daemon commit。

| OpenSpec 任务 | 操作 | 通过条件 |
| --- | --- | --- |
| 4.2 主机管理 | App 内「添加主机」分别用直连与 SSH 表单各配一台；主机管理屏切换、忘记单台 | 两类主机均可配对成功；切换后连接跟随；忘记后列表移除且下次连接重新 TOFU |
| 4.2 指纹变更确认 | 修改电脑 sshd host key（或换目标主机）再连 | 连接被拒并弹「信任新指纹」对话框；取消则不连接不改存储，确认后可连接 |
| 5.1 mDNS 发现 | 配对屏观察发现列表；关停 daemon 再观察 | daemon 启动即出现（名称/地址/指纹），关停后移除；`--localhost` 模式不出现在列表 |
| 5.1 空态降级 | 关闭 daemon 或用组播被抑制的网络观察配对屏 | 空态提示出现，手动输入表单照常可用 |
| 5.2 扫码配对 | 用 App 扫 daemon 横幅二维码；再扫一个无关二维码 | 有效码自动填齐地址/端口/配对码/指纹并一键配对；无效码提示且表单不动 |
| 6.1 LAN 端到端 | 全程只用 mDNS 点选或扫码完成配对 → 发任务 | 全程无手动输入地址/端口/指纹 |
| 6.2 SSH 端到端 | daemon 以 `--localhost` 启动，手机经 SSH 隧道配对 → 发任务 → 权限应答 → 杀 sshd 重连；有条件时换公网 SSH 跳板重复 | 全流程可用；断开恢复无需人工干预；锁屏期间隧道存活 |
| 6.3 文档一致性 | 按 CLAUDE.md 命令从零构建运行 | 与实现行为一致 |
