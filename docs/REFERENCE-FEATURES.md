# 参考项目功能清单（dsh-Go / happy-main）

> 对两个开源参考项目的功能盘点（2026-11-14，经评审修订），供产品规划参考。
> - **dsh-Go**：手机上直接运行 AI 引擎的安卓客户端（引擎跑在手机里）
> - **happy-main**：手机远程遥控电脑上 AI 编程助手的完整方案（CLI + 云端服务 + 双端手机 App）
>
> cc-go 与两者都有亲缘：连接与交互方式像 dsh-Go，驱动 AI 助手的方式像 happy-main。
>
> **打勾说明**：✅ = cc-go 已实现同等功能（个别功能真机验收进行中）。

## 0. 同一功能的两种叫法（阅读对照）

| 功能概念 | dsh-Go 的叫法 | happy-main 的叫法 |
|---|---|---|
| 远程主机 | 主机三分法（本机/SSH/中继） | 机器注册与守护进程 |
| AI 的权限模式 | 手机操控审批三档（每次问/名单免问/解除限制） | 七档权限模式（含"只读""全自动"等） |
| 防止消息重复丢失 | 事件带序号 | 单调序号 + 本地消息 ID 去重 |
| 信任一台电脑 | 主机指纹首连记录、变更即拒绝 | 挑战签名认证 + 扫码授权 |
| 手机与电脑配对 | 扫码 + 回输一次性数字码 | 配对码 / 扫码授权流程 |
| 传输加密 | 中继链路端到端加密（Noise 协议） | 每会话独立密钥端到端加密 |
| 聊天记录回看 | 代次重开 + 快照重同步 | 按序号增量拉取历史 |

## 1. dsh-Go 功能清单

### 连接方式
- **三种主机**：手机本机引擎 / SSH 远程电脑 / 官方中继，统一管理、一键切换
- **SSH 远程** ✅：手机直连电脑（支持密码或私钥），出门在外经跳板服务器也能用
- **连接状态可见**：连接中的每一步（引导、校验、转发、登录）都有进度提示；断线自动重连（✅）并区分"能重试"和"需要人工处理"两类错误（✅ 分错误类型，进度分步展示未做）
- **转发端口常驻**：网络抖动重连后聊天不中断、不重载
- **网络切换感知**：Wi-Fi 和流量切换、App 回到前台时自动检查并恢复连接
- **首次信任** ✅：首次连接记录电脑指纹，指纹突变立即拒绝并提示（防中间人）
- **扫码配对** ✅（单向出码版）：电脑出二维码，手机扫描自动填参配对；双向确认回输数字码未做
- **凭据安全** ✅：密码/私钥只存手机安全存储，不进普通配置文件
- **网络路径透明**：可查看当前走的是局域网直连、点对点还是中继

### 会话与聊天
- 会话管理：分组/文件夹、搜索、归档、批量操作（✅ 基础会话列表与自动刷新、按项目分组展示、分组折叠/隐藏空组/长按注销项目；搜索/归档/批量操作未做）
- 富文本聊天 ✅（部分）：Markdown（代码高亮、表格、列表、链接、复制）✅、流式传输中残缺 Markdown 自动容错 ✅、编辑类工具改动对比视图 ✅；数学公式/流程图未做
- 工具调用折叠 ✅：执行过程折叠成一行，可展开看完整轨迹；连续多次工具调用自动归并成组 ✅、整回合折叠 ✅、逐工具定制视图（命令/编辑对比/搜索/待办清单）✅、AI 思考过程可展开 ✅
- 三种发消息方式：插话（未做）/ 排队 ✅（等当前轮结束）/ 停止后发送 ✅；排队消息可提前发送（未做）
- 审批卡片 ✅：AI 请求敏感操作时弹卡确认（含"本次会话不再询问"）；过期代次作废未做
- 输入体验：语音听写（系统识别 + 可下载离线识别模型）、斜杠命令面板、@提及、引用、附件
- 目标与待办条：聊天输入框上方常驻显示当前目标和任务清单
- 附件与媒体：图片/文件发送，AI 生成的图片/视频可内嵌查看
- 会话详情页：对话、生成物、工作区文件多窗格查看
- 内置终端：手机上直接操作电脑终端
- 官方网页版功能全量镜像 + 兜底：每个官网功能都有原生实现或内嵌网页兜底
- 引擎设置可视化：引擎配置项生成表单直接在手机上改
- 工作区与文件浏览：切换工作目录 ✅（新建会话时在多个已注册项目目录中选择）、浏览/管理电脑文件未做
- 会话回放与导出 ✅（部分）：电脑上已有的会话可在手机端浏览、只读回放、一键接管续聊 ✅；分享链接/导出/删除未做

### 权限与安全
- 手机操控审批：AI 操控手机分三档授权；悬浮球/胶囊/卡片三种形态一键停止
- 应用自更新：多渠道检查 + 校验和验证 + 增量更新（省流量），安装过程事务化防"装一半"
- 诊断日志全量脱敏：导出的日志自动抹去密码、密钥、Cookie
- 锁屏通知脱敏：锁屏时通知只显示"有新消息"，解锁后显示内容
- 分享链接端到端加密：密钥只在链接里，服务端看不到内容

### 通知与保活
- 前台服务保活 ✅，锁屏长时间不中断
- 聊天通知 ✅：审批请求走高优先级提醒、任务结束普通提醒（按会话分组、新替旧未做）
- 常驻状态通知 ✅：如实展示连接状态
- **通知栏直接审批**：不打开 App 就能在通知上允许/拒绝
- 省电白名单引导 ✅（电池优化设置直达；厂商细分未做）

### 运行时（引擎在手机上的特殊能力）
- 免 root 运行完整 Linux 环境；引擎可分层升级（不用整包重装）
- 安全模式：连续启动失败自动禁用插件启动，可手动恢复
- 启动可靠性：启动缓存、崩溃自动分类、失败后给出可读原因
- 手机操控引擎：AI 可调用手机无障碍能力操作屏幕（配审批与悬浮条）
- 插件系统：声明式卡片/面板、按 App 版本自动降级、插件市场与创意工坊

### 个性化与周边
- 主题：六套配色、壁纸取色、玻璃质感、深浅色、图标可选
- 全页面深链直达、平板/横屏自适应布局
- 首次启动引导流、系统权限逐项引导
- 中英双语（文案与帮助文档同步检查）
- 诊断包一键导出
- 角色扮演模式（AI 角色卡、世界书、群聊）、AI 伙伴、桌宠、社区论坛（偏娱乐向）

## 2. happy-main 功能清单

### AI 驱动（电脑侧 CLI）
- 驱动 AI 编程助手：Claude Code ✅（多助手未做）；Codex/Gemini/兼容协议助手未做
- 长会话管理：会话可随时恢复 ✅（含把电脑终端上已有的会话导入手机接管续聊 ✅）；"回滚"到某个节点重跑未做
- 权限系统 ✅（基础）：弹卡审批 + "本次会话不再询问"；细粒度自动放行规则、权限档位实时切换未做
- 打断与排队 ✅：随时打断当前任务、运行中发送自动排队；审批卡片做成"状态" ✅（断线重连后待审批卡片仍在、可继续审批）
- 消息一致性 ✅（基础）：按条目整体替换、快照与实时流幂等合并；严格顺序保证与打断补全未做
- 手机端可浏览和编辑电脑文件：内置远程文件读写、目录树、全文搜索工具
- 用量与限额：API 用量统计与限额提醒
- 多助手统一抽象：不同 AI 助手对外呈现一致的会话体验

### 手机 App（iOS / Android 原生）
- 会话列表与聊天：会话列表 ✅、工具调用卡片 ✅、AI 子任务归并展示 ✅（连续工具调用成组）、改动对比视图 ✅（编辑类工具）；全轮次改动汇总视图未做
- 待审批卡片、权限档位切换器、打断/排队
- 语音模式：对 AI 说话（连续对话、自动断句），另有独立的"与 AI 语音通话"形态
- 多设备登录同一账号，多台电脑统一管理
- 附件/拍照发送、生成的图片带模糊占位渐进加载
- 通知 ✅：任务完成/需审批时本地通知（前台服务保活）；云端远程推送、"正在看不打扰"未做
- 附加能力：任务看板、生成物管理、内置浏览器、文档、保险库（密钥托管）

### 云端同步服务（可选自托管）
- 手机与电脑经云端中转同步：全量 API（认证、会话、消息、附件、用量统计）
- **端到端加密**：聊天内容、审批状态、附件等服务端都看不到，只存密文
- 实时通道 ✅：手机与电脑 WebSocket 直连指令（点对点 RPC 体系未做）
- 快照 + 增量合并 ✅（基础）：断线重连后按条目补齐、不重不漏；完整历史回放 ✅（走电脑本地会话记录分页回放，按序号增量的传输协议未做）
- 离线恢复 ✅（基础）：断线状态明示、恢复后自动重连补快照；离线会话态未做
- 推送服务：任务完成/需审批时推送到手机，支持 iOS/安卓
- 官方服务之外提供自托管打包（含轻量单机版）

### 电脑侧守护进程
- 后台常驻：开机自启、状态心跳、本地管理接口
- 电脑合盖/断网自动暂停重连，恢复后自动接上
- `happy resume` 一条命令恢复上次会话
- 环境体检（doctor）：一键检查安装与配置问题
